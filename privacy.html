Privacy Policy

Last updated: 24 November 2026

"Video TikTok Aura" is a personal tool used by a single person (its owner) with the owner's own TikTok account.

Data we access

With the owner's authorization (scope video.upload), the tool receives an access token and a refresh token for the owner's TikTok account. It uses them only to send draft videos to the owner's TikTok inbox and to read the status of those uploads.

How data is stored

Tokens are stored privately on the owner's own server, in a file readable only by the owner. They are never published, shared, sold or sent to third parties.

What we do not do

No analytics, no advertising, no profiling, no collection of data about other TikTok users.

Revoking access

Access can be revoked at any time in TikTok (Settings and privacy, Security and permissions, Apps and services). Tokens expire automatically and are deleted from the server on request.
